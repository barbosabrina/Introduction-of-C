# Introduction-of-C

Nesse repositório, apresento grande parte de todas aulas práticas que tive na matéria de Introdução a Programação.
onde tive o primeiro contato com a linguagem C. Os arquivos vão desde algoritmos básicos para mais completos, utilizando
de todas as funcionalidades da linguagem. Dessa forma, para fins avaliativos contém também o trabalho prático feito para
conclusão da matéria.
